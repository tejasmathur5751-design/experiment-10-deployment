# Experiment 10 – Website Deployment (Static on Netlify, Dynamic on Cloud)

## Aim
Deploy a static website on Netlify and a dynamic website on a cloud platform (Render/Heroku/AWS).

## Contents
- `index.html`: Interactive guide and live demonstration of static vs dynamic deployment workflows
- `style.css`: Responsive stylesheet
- `server.js`: Node.js Express dynamic server reference
- `package.json`: Configuration for cloud deployment

## Deployment
- **Static Site**: Deployed on GitHub Pages / Netlify directly from Git repository
- **Dynamic Site**: Node.js web service deployment with auto-build and start scripts
