About This Project

In this experiment, I learnt how to deploy websites online. A static website contains HTML, CSS and JavaScript files that can be hosted directly on platforms like Netlify or GitHub Pages without needing a backend server.

For the dynamic part, a Node.js and Express server runs in the cloud to handle API requests and send responses.

Deployment Summary

Static Deployment

Platform: Netlify / GitHub Pages

Files: index.html, style.css, script.js

Features: Free hosting, automatic HTTPS, fast loading

Dynamic Deployment

Platform: Render / Heroku / AWS

Backend: Node.js & Express

Features: API routes, handles data, database connection
