Static Website Deployment – Netlify

A static website contains only HTML, CSS and JavaScript files. No server-side processing is needed. Netlify is a popular platform for deploying static sites directly from a GitHub repository.

Steps to Deploy on Netlify

  1. Push your HTML/CSS/JS project to a GitHub repository.
  2. Go to netlify.com and sign in with your GitHub account.
  3. Click "Add new site" → "Import an existing project".
  4. Select your GitHub repository from the list.
  5. Set the build command (leave blank for plain HTML) and publish directory (e.g., / or dist).
  6. Click "Deploy site". Netlify builds and publishes your site.
  7. Your site is live at a URL like your-site.netlify.app.
netlify.toml (optional configuration file)
[build]
  publish = "."
  command = ""

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200

Dynamic Website Deployment – Cloud Platform

A dynamic website has a backend server (e.g., Node.js + Express) that processes requests and returns data. It needs a platform that can run server-side code — such as Render, Railway or Heroku.

Steps to Deploy Node.js App on Render

  1. Ensure your project has a package.json with a start script: "start": "node server.js".
  2. Push the project to a GitHub repository.
  3. Go to render.com and sign in.
  4. Click "New" → "Web Service" and connect your GitHub repo.
  5. Set Runtime to Node, Build command to npm install, Start command to npm start.
  6. Click "Create Web Service". Render installs dependencies and starts the server.
  7. Your app is live at a URL like your-app.onrender.com.
package.json
{
  "name": "web-app",
  "version": "1.0.0",
  "main": "server.js",
  "scripts": {
    "start": "node server.js"
  },
  "dependencies": {
    "express": "^4.18.2"
  }
}
